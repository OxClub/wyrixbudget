# Release checklist (Phase 8 and 9)

What I could and could not do: I prepared configuration, tests and this checklist. I **cannot** build a signed
bundle, test on physical devices, measure real-device performance or publish: those need your machine, your
keystore and your Play Console account.

## 1. Before building
- [ ] Gradle sync succeeds; fix any compile or version issues.
- [ ] All unit and instrumented tests pass (TESTING.md).
- [ ] Replace `AppInfo.SUPPORT_EMAIL` with a real address.
- [ ] Have the privacy policy and terms (`AppInfo.kt`) reviewed; host the policy on a public URL (Play requires one).
- [ ] Check `IndianTaxRules` against the current Finance Act; review the tax disclaimer wording.
- [ ] Check dependency versions in `gradle/libs.versions.toml` for security updates.
- [ ] Verify Google Play's current `targetSdk` requirement and raise `targetSdk`/`compileSdk` if needed; re-test.
- [ ] Commit `app/schemas/` (generated by the first build).

## 2. Signing
```
keytool -genkeypair -v -keystore wyrix-release.jks -alias wyrix -keyalg RSA -keysize 4096 -validity 10000
```
Create `keystore.properties` in the project root (it is git-ignored):
```
storeFile=wyrix-release.jks
storePassword=...
keyAlias=wyrix
keyPassword=...
```
Back up the keystore and passwords somewhere safe; use Play App Signing.

## 3. Build
```
./gradlew clean bundleRelease          # app/build/outputs/bundle/release/app-release.aab
```
- [ ] Install a release build (via `bundletool` or an internal-testing track): R8 is on, so test backup/restore
      (Gson field names are kept by `proguard-rules.pro`), receipts/OCR, reports and notifications in *release*, not just debug.
- [ ] Upload `app/build/outputs/mapping/release/mapping.txt` to Play Console for readable crash traces.

## 4. Device matrix (minimum)
Android 8 (API 26), 10, 12, 13/14, latest; a small-screen phone, a large phone, a tablet; one low-RAM device.

## 5. Performance
Targets: cold start under 2 s on a mid-range phone; 60 fps scrolling in the transaction list with 10k+ rows;
analytics under 1 s. Profile with Android Studio's profiler and, if you want regression tracking, add Macrobenchmark.

## 6. Play Console
- [ ] Store listing from `PLAY_STORE.md`; screenshots (phone, 7" and 10" tablet), feature graphic, icon 512x512.
- [ ] Data safety form: see `PLAY_STORE.md`.
- [ ] Content rating questionnaire; target audience (not for children); no ads declaration.
- [ ] Testing track: check the *current* testing requirements for new developer accounts before planning your launch date.
- [ ] Staged rollout (e.g. 10% → 50% → 100%) and watch crash-free rate.

## 7. After launch
Monitor Play vitals; keep a changelog; every schema change = new `Migration` + migration test.
